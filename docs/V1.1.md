# Börü V1.1

V1.1, V1.0 güvenlik sınırlarını koruyarak salt-okunur genel ajan döngüsü ve
değişiklik-duyarlı yerel kod indeksi ekler.

## Başlatma

```powershell
python main.py
```

## Genel ajan

```text
ajan: kullanıcı mesajı hangi sınıfta işleniyor ve yanıt akışı nasıl ilerliyor?
```

Ajan en fazla altı turda yalnızca kayıtlı salt-okunur araçları kullanabilir:

- proje özeti;
- dosya/klasör okuma;
- kod ve sembol arama;
- Python dosyası sembol listesi.

Final yanıt yalnızca başarılı araç gözlemlerine dayanıyorsa `TAMAMLANDI`
olur. Katalog dışı araçlar, tekrarlanan çağrılar, geçersiz structured çıktı ve
kanıtsız final yanıt fail-closed davranır.

V1.1 ajanı dosya değiştirmez ve terminal komutu çalıştırmaz. Değişiklikler
V1.0'daki `iyileştir:` veya kontrollü Coding Agent akışında açık onayla yapılır.

## Manuel doğrulama

```text
ajan: AssistantService sınıfı hangi dosyada ve kullanıcı mesajını işlerken hangi ana adımları uyguluyor?
```

Beklenen: Ajan kod arama ve dosya okuma araçlarından en az birini kullanır,
`AJAN RAPORU / TAMAMLANDI` döndürür ve `T` numaralı kanıtları listeler.
