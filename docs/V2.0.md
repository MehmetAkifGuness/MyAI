# Börü V2.0

V2.0, planlı görev durumunu proje bazlı kalıcı checkpoint ile korur.

- Plan, task durumları ve son 100 durum olayı atomik JSON belgesine yazılır.
- Uygulama yeniden başladığında tamamlanmış ve bekleyen tasklar geri yüklenir.
- Yarım kalan `running` task güvenli biçimde `pending` yapılır; eski diff/onay yeniden kullanılmaz.
- `planı devam ettir` ilk hazır task için güncel kaynaklardan yeni öneri oluşturur.
- `görev günlüğü` son checkpoint olaylarını ve saklama yolunu gösterir.
- Bozuk, aşırı büyük, uyumsuz veya secret biçimli içerik taşıyan checkpoint reddedilir.
- Her task için açık diff onayı ve Test/Security/Code Review doğrulaması korunur.
