# Börü V1.4

V1.4, doğal dil değişiklik hattına hedef odaklı hata teşhisi ekler.

- Açık dosya yolu olmadan benzersiz test, sınıf, sembol veya dosya gövdesi bulunabilir.
- Bir test dosyasının proje içi import ilişkilerinden olası uygulama dosyası belirlenir.
- Test kanıt olarak korunur; yalnızca en güçlü ve tekil uygulama dosyası değişiklik kapsamına alınır.
- Başlangıç test hatası, Coding Agent görevine sınırlandırılmış doğrulama kanıtı olarak aktarılır.
- Test sözleşmesini değiştirmek yerine uygulamadaki kök nedeni düzeltme yönlendirmesi yapılır.
- Mevcut açık onay, geçici sandbox doğrulaması, geri alma ve yeniden öneri güvenliği korunur.
