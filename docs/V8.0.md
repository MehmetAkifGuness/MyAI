# Börü V8.0

V8.0, uzun süren model karşılaştırmalarını izlenebilir ve durdurulabilir yapar.

```text
benchmark çalıştır: qwen2.5-coder:7b | yedek=qwen3.5:9b | limit=30 | tekrar=2
benchmark durumu
benchmark iptal
```

- Durum çıktısı tamamlanan/toplam değerlendirmeyi, aktif model ve görevi, son sonucu ve ETA'yı gösterir.
- İptal, devam eden sınırlı model çağrısı tamamlanınca yeni değerlendirme başlatmadan kısmi rapor üretir.
- `yedek=` modeli; ana model geçersiz structured çıktı, beklenmeyen açıklama isteği veya başarısız test sonucu verdiğinde otomatik devreye girer.
- JSON raporu kullanılan modelleri, ilk başarısız durumu, yönlendirme sayısını, ortalama süreyi ve düzeltilmiş insan müdahalesi sayısını içerir.

Uygulama structured yeniden denemelerinde `BORU_FALLBACK_MODEL` ayarlanmışsa ilk denemede
`BORU_MODEL`, sonraki denemede yedek modeli kullanır. Ayar yoksa önceki tek-model davranışı korunur.

PowerShell örneği:

```powershell
$env:BORU_MODEL='qwen2.5-coder:7b'
$env:BORU_FALLBACK_MODEL='qwen3.5:9b'
python main.py
```
