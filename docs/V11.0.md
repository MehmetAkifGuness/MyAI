# Börü V11.0

V11.0, repo görevlerini kod üretiminden önce deterministik olarak anlamlandırır.

- Görevi hata düzeltme, özellik, test, refactor veya araştırma olarak sınıflandırır.
- Kod indeksinden ilgili dosya ve test adaylarını gerekçeleriyle çıkarır.
- Belirsiz görevlerde değişiklik önermek yerine tek ve hedefli bir soru sorar.
- Netleştirilmiş hedefi ve güvenilmeyen kanıt bağlamını güvenli biçimde Coding Agent'a aktarır.
- Repo içeriğini çalıştırmaz ve dosya kapsamı/onay/doğrulama korumalarını değiştirmez.

Komutlar:

```text
repo akıllı analiz: hedef
repo akıllı geliştir: hedef
```
