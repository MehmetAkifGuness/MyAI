# Börü V2.1

V2.1, kalıcı görev planlarını kaynak dosya değişimine karşı korur.

- Plan kapsamındaki mevcut dosyaların SHA-256 özetleri checkpoint'e yazılır.
- Task başlamadan önce kayıtlı özetler güncel dosyalarla karşılaştırılır.
- Dosya değişmiş veya silinmişse eski plan uygulanmaz ve güncel kaynakla yeniden planlama istenir.
- Börü'nün doğrulanmış task değişikliği tamamlandığında ilgili özet güvenli biçimde yenilenir.
- V2.0 checkpoint'leri okunmaya devam eder; kaynak özeti olmayan tamamlanmamış eski planlar güvenli tarafta durdurulur.
