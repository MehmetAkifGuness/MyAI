# Börü V4.0 — V3.1–V4.0 geliştirme paketi

V4.0, güvenli Docker terminalini proje bağlamı ve kontrollü geliştirme döngüsüyle genişletir.

| Sürüm | Yetenek |
| --- | --- |
| V3.1 | Proje sınırı içinde durumlu çalışma dizini (`terminal cd`, `terminal pwd`). |
| V3.2 | Canonical komutlardan oluşan, son 50 kaydı tutan kalıcı terminal geçmişi. |
| V3.3 | Docker içindeki gerçek Python, platform, executable ve çalışma dizini raporu. |
| V3.4 | Ağ kullanmadan `pip check` ile kurulu bağımlılık tutarlılığı denetimi. |
| V3.5 | Geçici `/tmp` bytecode alanında `compileall` syntax doğrulaması. |
| V3.6 | Compile, Ruff ve mypy aşamalarını shell olmadan ayrı ayrı çalıştıran kalite hattı. |
| V3.7 | Mevcut 120 saniye, 1 MB çıktı, CPU/RAM/PID sınırlarının bütün terminal türlerine uygulanması. |
| V3.8 | Komut, çalışma dizini, sonuç ve çıkış kodu için güvenli denetim günlüğü. |
| V3.9 | Shell operatörü, serbest Python, mutlak/üst dizin ve ek bayrak saldırılarına kapalı terminal politikası. |
| V4.0 | Doğal dil hedefini görev planına çevirip ilk öneriyi hazırlayan ve onay sonrası doğrulamalı task zincirini sürdüren geliştirme döngüsü. |

## Komutlar

```text
terminal durumu
terminal ortamı
terminal cd: boru
terminal pwd
terminal: compileall tasks
terminal: pip check
terminal kalite: tasks
terminal geçmişi
otonom geliştir: boru/example.py içindeki hatayı bul, düzelt ve doğrula
otonom durum
otonom devam et
otonom iptal
```

Otonom akış planlama ve araştırmayı kendisi yürütür. Her kaynak değişikliği için mevcut açık onay sözleşmesi devam eder. Onaylanan her task sonrasında Test, Security ve Code Review çalışır; başarısız doğrulama planı durdurur. Plan en fazla 12 task, task başına 3 deneme ve 7 günlük geçerlilik sınırındadır.

Terminal genel shell değildir. Ağ, paket kurulumu, yönlendirme, pipe, `python -c`, serbest bayraklar ve workspace dışı yollar reddedilir. Kalite hattındaki aracın sandbox imajında bulunmaması ilgili aşamayı başarısız yapar; otomatik kurulum yapılmaz.
