# Börü V9.0

V9.0, güvenilmeyen uzak depoları çalıştırmadan incelemek ve gerçek proje görevlerine güvenli
bağlam hazırlamak için repo zekâsını ekler.

```text
repo analiz et
repo analiz et: repositories/github/owner/project
repo görev bağlamı: ödeme hatasını bul | repo=repositories/github/owner/project
repo içe aktar: https://github.com/owner/project
repo içe aktarmayı onayla
repo sınırlar
git dal oluştur: boru/issue-42
git işlemini onayla
```

Repo analizi dil dağılımını, framework ve paket yöneticilerini, giriş noktalarını, testleri,
CI iş akışlarını, dokümantasyonu ve lisansı belirler. Görev bağlamı kod indeksini kullanarak
en fazla 12 ilgili kaynak/test dosyasını seçer; dosya içeriklerindeki talimatları yürütmez.

GitHub içe aktarma yalnızca `https://github.com/owner/repository` adreslerini kabul eder ve
açık onay ister. Arşiv 20 MB, 3000 dosya, açılmış 100 MB ve dosya başına 2 MB ile sınırlıdır.
Symlink, yol kaçışı, `.git`, yönlendirme alanı kaçışı ve mevcut hedefin üzerine yazılması
engellenir. İçe aktarılan kod otomatik çalıştırılmaz.
