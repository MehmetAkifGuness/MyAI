# Börü V1.2

V1.2, genel ajana proje içi Python import ve çağrı ilişkisi keşfi ekler.

## Başlatma

```powershell
python main.py
```

## Davranış

Bir sınıf veya dosya sorusunda ajan:

1. sembolü güvenli kod indeksinde arar;
2. ana kaynak dosyayı okur;
3. proje içi importları gerçek dosyalara çözer;
4. kaynakta çağrılan metotlara göre ilişkili dosyaları sıralar;
5. en ilgili iki yardımcı dosyayı okur;
6. bütün kanıtlardan tek final yanıtı üretir;
7. ret, izin ve kanıtsız yanıt sorularında koşul/olumsuzluk yorumunu ikinci
   structured doğrulama geçişiyle kontrol eder.

Dosya sistemi erişimi salt-okunur kalır. Harici paketler, dinamik importlar ve
çalışma zamanında oluşturulan çağrılar statik ilişki indeksinin kapsamı dışındadır.

## Manuel test

```text
ReadOnlyToolAgent sınıfı hangi dosyada ve kanıtsız final yanıtını nasıl engelliyor?
```

Beklenen kanıtlar ana `runtime.py` dosyasına ek olarak `reporting.py` ve gerekirse
`final_synthesis.py` dosyalarını içermelidir.
