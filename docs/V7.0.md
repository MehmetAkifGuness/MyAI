# Börü V7.0 birleşik ajan paketi

Başlatma: `python main.py`

Sohbet içinden kullanım:

```text
benchmark görevleri
benchmark çalıştır: qwen2.5-coder:7b | limit=5
benchmark durumu
```

`python -B -m boru.benchmark --model qwen2.5-coder:7b --limit 5` biçimi de
Börü sohbetinde güvenli biçimde tanınır. İşlem arka planda yürür; sonuç için
`benchmark durumu` yazılır. Aynı CLI komutu PowerShell'de de doğrudan kullanılabilir.

V7.0, V6.4–V6.6 çalışmalarını tek akışta birleştirir:

1. Structured çıktı doğrulanır; model/provider veya şema hatasında en fazla bir kez,
   doğrulama hatasıyla yeniden istenir.
2. Açık dosya kapsamı yoksa güvenli proje manifesti görev terimleri ve kod indeksiyle
   sıralanır. Eşleşme bulunduğunda ilgili kaynak/test kardeşleri korunur ve modele en
   fazla 40 aday aktarılır; kanıt yoksa güvenli manifest daraltılmadan bırakılır.
3. Onaylanan kod önerisi önce geçici proje kopyasında uygulanır ve Docker içinde test
   edilir. Başarısız veya kanıtsız sonuç ana projeye yazılmaz.
4. Test gerçekten başarısızsa çıktı Coding Agent'a bir kez geri verilir. Yeni diff
   tekrar açık kullanıcı onayı ister. Test bulunamaması otomatik kod değişikliğine yol açmaz.

Model kalitesi için benchmark da aynı sınırlı döngüyü ölçer: structured düzeltme,
sandbox testi ve en fazla bir test-geri-bildirimli kod onarımı.

```powershell
python -B -m boru.benchmark --list
python -B -m boru.benchmark --model qwen2.5-coder:7b --limit 5
python -B -m boru.benchmark --model qwen2.5-coder:7b --model qwen3.5:9b --limit 30 --repeats 2
```

JSON rapor şeması `boru.benchmark/v2`'dir. Model çağrısı, structured yeniden deneme,
test onarımı, insan müdahalesi, durum dağılımı, süre ve kodlama başarı oranı kaydedilir.
Token ve ücret bilgisi Ollama adaptörü tarafından sağlanmadığı için `null` kalır.

## Güvenlik ve kapsam

- Model yalnızca güvenli manifestte bulunan dosyaları değiştirebilir.
- Benchmark kabul testleri ilk model isteminde bulunmaz; hata çıktısı onarım turunda verilir.
- Üretilen benchmark kodu yalnızca ağsız Docker sandbox içinde çalıştırılır.
- Model geri bildirimi en fazla iki structured deneme ve bir test onarımıyla sınırlıdır.
- Bu hâlâ küçük sentetik bir değerlendirmedir; Codex eşdeğerliği, gerçek proje başarısı,
  kötü niyetli test manipülasyonuna karşı tam güvenlik veya iş gereksinimlerinin tamamını
  garanti etmez.
- GitHub uzak depo alma ve bulut model sağlayıcıları bu sürümde yoktur; çalışma alanındaki
  yerel proje analiz edilir.
