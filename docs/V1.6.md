# Börü V1.6

V1.6, genel ajana kanıtlı hedefli çalışma zamanı testi ekler.

- `run_targeted_test` yalnızca mevcut ve açıkça test olarak adlandırılmış Python dosyalarını kabul eder.
- Runner yalnızca `unittest` veya `pytest` olabilir; serbest shell ve serbest Python çalıştırılmaz.
- Test ağsız, salt-okunur, kaynaksız yetkili Docker sandbox içinde çalışır.
- Başarısız test araç hatası sayılmaz; traceback ve test özeti çalışma zamanı kanıtı olur.
- Geçen, başarısız, zaman aşımına uğrayan ve ayrıştırılamayan sonuçlar ayrılır.
- Genel ajan test sonucunu ek model çağrısı olmadan deterministik raporlar.
