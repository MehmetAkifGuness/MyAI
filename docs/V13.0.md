# Börü V13.0 — web araştırması, kaynaklı yanıtlar ve gündelik sohbet

Güncel sohbet üretim ayarları, model karşılaştırması ve bilinen başarısız canlı test:
[Sohbet değerlendirmesi](CHAT_EVALUATION.md). Aşağıdaki ilk canlı denemelerin ardından
sohbet istemcisi 90 saniye/1024 token sınırı ve qwen3 için kapalı düşünme profiline geçti.

PowerShell'de `python main.py` ile başlatın. Sohbet komutlarını ayrı mesajlarda gönderin:

```text
web durum
web ara: Python json.loads resmi dokümantasyon
web oku: https://docs.python.org/3/library/json.html | json.loads ne yapar?
web araştır: Python json.loads ile json.load arasındaki fark nedir?
internetten Python json modülünü araştır
```

`web ara` bağlantıları listeler; bu aşamada sayfalar okunmuş sayılmaz. `web oku` belirtilen
sayfayı okuyup soruyu yanıtlar. Soru verilmezse kısa Türkçe özet ister. `web araştır`
en fazla beş arama sonucu içinden üç sayfayı okur ve kaynakları numaralandırır.
`site:docs.python.org` gibi bir kısıt varsa sonuçların alan adı ve istenen yol Börü'de
kontrol edilir. Başlık/URL/açıklamasında sorguyla eşleşmeyen sonuçlar elenir; okunan
sayfa da tekrar kontrol edilir. Bu basit ilgi filtresi ilgili sonuçları kaçırabilir.
`site:` ile belirli bir sayfa yolu yazılmışsa ve arama sonuçsuzsa o adres doğrudan
okunabilir; bunun arama sonucu olmadığı yanıtta belirtilir.
Sohbette yalnızca açık web komutları internete çıkar. Kodlama ajanının kendi kendine web
aramaya karar vermesi ve araştırmanın kod düzenleme bağlamına otomatik aktarılması bu sürümde yoktur.

## Sağlayıcılar

Anahtarsız kullanımda DuckDuckGo HTML, sonuç alınamazsa Bing RSS denenir. Bunlar herkese
açık arama arayüzleridir; CAPTCHA, kota, biçim değişikliği veya ilgisiz sonuçlar olabilir.
Brave API yapılandırılmışsa yalnızca o sağlayıcı kullanılır:

```powershell
$env:BORU_WEB_SEARCH_KEY="Brave panelinden aldığınız anahtar"
python main.py
```

Bu PowerShell ayarı sohbet kutusuna yazılmaz. Bir API hesabı/ücretli plan otomatik açılmaz.
Anahtar yalnızca Brave arama adresine HTTP başlığında gönderilir; modele veya kaynak sitelere
aktarılmaz. Sorgu seçilen arama sağlayıcısına gider. Proje dosyaları, konuşma geçmişi ve
hafıza kayıtları web sorgusuna eklenmez. Hassas anahtar/parola biçimleri gönderimden önce
reddedilir; bu kontrol her tür kişisel veriyi tanıyan bir anonimleştirme sistemi değildir.

Sağlayıcı belgeleri:
[DuckDuckGo HTML/Lite](https://safe.duckduckgo.com/duckduckgo-help-pages/features/non-javascript),
[Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started).
Bing RSS yedeğinin kararlı bir API sözleşmesi garantisi yoktur.

## Okuma ve yanıt kalitesi

- Yalnızca HTTPS/443; URL kimlik bilgileri, özel/yerel IP'ler ve özel DNS sonuçları reddedilir.
  Bağlantı doğrulanmış IP'ye açılır, TLS sertifikası asıl alan adına göre kontrol edilir.
  Her yönlendirme yeniden denetlenir; anahtarlı arama yönlendirilmez. Ortam proxy'si kullanılmaz.
- Sayfa başına 1 MB, en fazla üç yönlendirme, ağ işlemlerinde 20 saniyelik bütçe.
  İşletim sisteminin DNS çözümlemesi bu süreyi aşabilir; bu bir toplam araştırma süre garantisi değildir.
  HTML/metin okunur; JavaScript çalıştırılmaz, PDF ve dosya indirmeleri desteklenmez.
- Script, gezinme alanı ve açıkça gizlenmiş HTML parçaları çıkarılır. Soruyla eşleşen
  pasajlar açıklama komşularıyla birlikte seçilir; tek başına kod örneklerine öncelik verilmez.
  Reklam duvarı, oturum açma veya JavaScript gerektiren sayfa tam okunamayabilir.
- Her yanıt maddesi mevcut bir kaynak numarası ve o kaynakta gerçekten geçen kısa alıntı
  gerektirir. Yanlış numara/uydurma alıntı reddedilir, model bir kez geri bildirimle yeniden dener.
  Doğrulanamazsa başarılı yanıt yerine açıkça etiketli kısa kaynak alıntıları gösterilir.
- Aynı yanıt maddesinin tekrarı ve alıntıda bulunmayan hata/exception adı reddedilir.
- Kaynak bulunamadığında modelin genel bilgisinden web yanıtı üretilmez. Erişim tarihi
  yayın tarihi olarak sunulmaz. Okunamayan sayfalar belirtilir.
- Alıntının mevcut olması, modelin yorumunun anlamsal doğruluğunu tek başına kanıtlamaz.
  Çelişki, güncellik ve tüm alt soruları kapsama model kalitesine bağlıdır. Web içeriği
  güvenilmeyen veri olarak modele verilir; yanıt üreticisinin kod çalıştırma/yazma aracı yoktur.

Bu katman kaynak erişimini ve yanıt denetimini iyileştirir; model ağırlıklarını eğitmez.
Kaynaklar yalnızca o istek boyunca bellekte tutulur; kalıcı web indeksi veya takip sorusu
oturumu oluşturulmaz. Bekleyen yazma onayları mevcut işlem akışında önceliğini korur.

## Doğrulama

```powershell
python -B -m unittest tests.test_v13000 tests.test_conversation_quality
$env:BORU_LIVE_WEB="1"
python -B -m unittest tests.test_v13000_live
```

Canlı test Ollama'da `qwen2.5-coder:7b` gerektirir; yalnızca resmî Python belgesini okur.

10 Eylül 2026 doğrulaması: web katmanında 31 hedefli test geçti.
Tüm test keşfinde 905 test değerlendirildi: 884 geçti, 21 isteğe bağlı test atlandı.
Canlı ağ denemesinde Python belgesi okundu. DuckDuckGo HTTP 202 döndürdüğünde Bing RSS
yedeği gerçek bağlantılar getirdi. Yerel modelle doğrudan belge okuma testi 23,301 saniyede
geçti: `json.loads` açıklaması ve `JSONDecodeError` yanıtı tekrarsız, kaynak bağlantısıyla
üretildi. Bu tek örnek diğer sorularda doğruluk veya aynı hız garantisi değildir.

Uçtan uca `web araştır` denemesinde `site:docs.python.org/3/library/json.html`
kısıtıyla ilgili arama sonucu alınamadığında belirtilen belge doğrudan okundu;
yerel model doğru açıklamayı ve `JSONDecodeError` yanıtını kaynaklandırdı.
Bu sonuç başarılı genel arama kapsamı veya arama sağlayıcısı erişilebilirliği garantisi değildir.

## Gündelik sohbet

- Günlük yer/marka soruları sırf özel ad içerdiği için kod ajanına yönlendirilmez.
- `Az önce ...` gibi yakın konuşma göndermeleri kalıcı hafıza yanıtıyla kesilmez.
  Açık kalıcı hafıza soruları mevcut retrieval davranışını korur.
- Uzun araç raporlarının modele gönderilen kopyası baş/son bilgileri korunarak
  kısaltılır; kayıtlı konuşma değiştirilmez. Kısaltılan ayrıntılar hatırlanamayabilir.
- Doğal Türkçe, isteğe uygun uzunluk, tavsiye istenmediğinde dinleme ve gereksiz
  takip sorularından kaçınma yönergeleri eklenmiştir. Bunlar model davranışını
  yönlendirir; her yanıtta anlamsal doğruluk veya empati garantisi değildir.
- Boş yanıt, yalnızca düşünce bloğu, sorunun aynen tekrarı ve yinelenen uzun cümle
  gibi belirgin sorunlarda en fazla bir yeniden üretim yapılır. Yapılandırılmış
  bir model yedeği varsa ikinci denemede kullanılabilir. Bu ek çağrı gecikmeyi artırabilir.

Kodlama modelini değiştirmeden ayrı bir sohbet modeli kullanılabilir. Örneğin,
bu makinede kurulu `llama3.1:latest` ile denenen ayar (PowerShell'de):

```powershell
$env:BORU_CHAT_MODEL="llama3.1:latest"
python main.py
```

Model indirilmez; ayar boşsa mevcut `BORU_MODEL` kullanılır. Ayrı model ilk kullanımda
yüklenebilir; model geçişleri RAM/VRAM ve yanıt süresini etkiler. Web/kod araçları
bu ayardan bağımsız mevcut model yönlendirmesini kullanır.

Sohbette ayrı mesajlarla deneyin:

```text
Yarın matematik sınavım var, biraz gerginim. Tavsiye istemiyorum, biraz sohbet edelim.
Az önce neye hazırlandığımı söylediğimi hatırlıyor musun?
Aslında sınav yarın değil, cuma günü. Bundan sonra bunu esas al.
Sınavım ne zamandı?
```

İsteğe bağlı gerçek model testi:

```powershell
$env:BORU_LIVE_CHAT="1"
python -B -m unittest tests.test_conversation_live
```

Canlı iki turluk denemede matematik sınavı bilgisi hatırlandı ve kod/hafıza aracı
yanlışlıkla çalışmadı. Bununla birlikte küçük yerel model gereksiz soru/kalıp ifade
üretebildi; sohbet kalitesi için bu tek deneme kapsamlı bir değerlendirme değildir.
Model ağırlıkları eğitilmedi ve insan düzeyinde sohbet başarısı iddia edilmez.
Karşılaştırma için aynı canlı test `BORU_LIVE_CHAT_MODEL=qwen3.5:9b` ile de denendi;
ilk yanıtta 120,877 saniyede `ReadTimeout` oluştu. Bu model için sohbet kalite testi
tamamlanamadı. Üretimde ayrı sohbet modeli istemcisinin sınırı 180 saniyedir;
bu daha uzun süre hızlı veya başarılı yanıt garantisi değildir. Varsayılan model değiştirilmedi.
