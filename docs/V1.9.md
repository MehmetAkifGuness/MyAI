# Börü V1.9

V1.9, mevcut Task/Plan grafiğini bağımlılık sırasıyla kontrollü biçimde yürütür.

- `planı çalıştır` ilk hazır taskın Orchestrator önerisini başlatır.
- Her task için diff ayrı açık onay bekler; toplu veya örtük yazma yapılmaz.
- Onaylanan task Test, Security ve Code Review aşamalarından geçmeden tamamlanmaz.
- Başarılı task sonrasında sıradaki bağımlı taskın önerisi otomatik hazırlanır.
- Başarısız, blocked veya iptal edilen adım plan yürütmesini güvenli biçimde durdurur.
- Her task yalnızca kendi dosya kapsamını düzenleyebilir; genel hedef yalnızca bağlam sağlar.
- Plan ve ilerleme bilgisi yalnızca mevcut uygulama oturumunda tutulur.
