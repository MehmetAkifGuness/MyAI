# Börü V6.1–V6.3 başlangıç paketi

Tarihsel sürüm girişi: `python main_v6300.py`. Güncel `python main.py` daha yeni
varsayılan sürümü başlatır.

## Değişiklik doğrulaması

Coding Agent ve onu kullanan task/otonom akışlar, açık onaydan sonra öneriyi
önce geçici proje kopyasına uygular. İlişkili testler ve statik kontroller Docker
üzerinden değerlendirilir. Başarısızlık, eksik kanıt, güncelliğini kaybetmiş sonuç
veya doğrulama sırasında proje değişikliği varsa asıl kaynaklara yazılmaz.
Başarılı değerlendirmeden sonra mevcut hash kontrollü transaction uygulanır.
Bu koruma genel dosya oluşturma komutunu veya bütün yazma araçlarını kapsamaz.
Sandbox ve statik taramalar kapsamlı güvenlik garantisi değildir.

## Model ölçümü

```powershell
python -B -m boru.benchmark --list
python -B -m boru.benchmark --model qwen2.5-coder:7b --case addition --limit 1
python -B -m boru.benchmark --model qwen2.5-coder:7b --model qwen3.5:9b --limit 30
```

Yalnızca makinenizde kurulu model adlarını kullanın. Model indirilmez.
Docker Linux motoru ve `boru-sandbox:1.0` imajı gereklidir; üretilen kod
ana makinede çalıştırılmaz. Raporlar `data/benchmarks/` altında ayrı JSON
dosyalarına yazılır. `--output` var olan raporun üzerine yazmaz.

30 küçük sabit görev vardır: 15 hata düzeltme, 5 yeni fonksiyon, 5 ilişkili
dosya görevi ve 5 açıklama isteme senaryosu. V6.3'te her model aynı girdileri,
taze geçici dizinde tek öneri hakkıyla alıyordu. Kabul testleri ilk model istemine verilmez.
İlişkili dosya görevleri her iki dosyanın değiştirilmesini zorunlu kılmaz.
Açıklama isteme sorularının niteliği insan değerlendirmesi gerektirir ve kodlama
başarı sayısına katılmaz. Bu küçük sentetik set, gerçek proje başarısını veya
Codex ile eşdeğerliği kanıtlamaz. V7.0'dan itibaren sınırlı test-geri-bildirim
döngüsü eklenmiştir. Kötü niyetli
kodun test mekanizmasını yanıltmasına karşı tam korumalı bir değerlendirme değildir.

Karşılaştırma mevcut ortak structured model arayüzü üzerinden yapılır; CLI
şimdilik yalnızca Ollama modellerini destekler. Bulut sağlayıcı adaptörü eklenmedi.
Süre, çıktı durumu ve görev kümesinin SHA-256 özeti kaydedilir. Token/maliyet
verisi ölçülmediğinden `null` bırakılır. Donanım, model sürümü ve sıcak/soğuk
başlangıç süreleri karşılaştırmayı etkiler.

`--repeats` 1–3, `--budget-seconds` 1–7200 kabul eder. Toplam süre bütçesi görevler
arasında kontrol edilir; devam eden model çağrısının (180 sn) ve sandbox işleminin
kendi süre sınırları vardır. Bu nedenle toplam süre bütçeyi aşabilir.

## Doğrulama

```powershell
python -B -m unittest tests.test_v6300 tests.test_v6000 tests.test_v1000
```

Birim testlerinde yalnızca elle yazılmış güvenilir örnekler yerel test yürütücüsü
ile çalıştırılır. Canlı model çıktısı için benchmark CLI daima Docker kullanır.
