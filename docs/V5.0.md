# Börü V5.0 — V4.1–V5.0 denetimli otonomi paketi

V5.0, V4.0'ın onaylı geliştirme döngüsünü tek bir güvenli kontrol yüzeyine dönüştürür.
Kaynak değişiklikleri hâlâ açık kullanıcı onayı olmadan uygulanmaz.

| Sürüm | Yetenek |
| --- | --- |
| V4.1 | Otonom komutlarda sınırlı ve güvenli Türkçe yazım toleransı. |
| V4.2 | Kaynak değişikliği başlatmadan yalnızca görev planı hazırlama. |
| V4.3 | Hazır planı ayrı bir komutla kontrollü başlatma. |
| V4.4 | Bekleyen öneriyi iptal ederek task'ı güvenli biçimde duraklatma. |
| V4.5 | Kalıcı checkpoint üzerinden planı sürdürme. |
| V4.6 | Yalnızca `failed` task için mevcut üç denemelik sınırı kullanan retry. |
| V4.7 | En fazla 12 göreli Python yolu için Docker tabanlı hedefli doğrulama. |
| V4.8 | Görev durumu ile işlem günlüğünü tek özet raporunda birleştirme. |
| V4.9 | Tamamlanmış planı arşivleme ve çalışma sınırlarını raporlama. |
| V5.0 | Bu yetenekleri tek denetimli otonom geliştirme kontrol merkezinde sunma. |

## Komutlar

```text
otonom geliştir: hedef
otonom planla: hedef
otonom başlat
otonom duraklat
otonom sürdür
otonom yeniden dene: TASK-1
otonom doğrula: kaynak.py ve tests/test_kaynak.py
otonom özet
otonom arşivle
otonom sınırlar
otonom yardım
otonom denetimli geliştir: hedef
```

`otonom geliştir` planı hazırlar ve ilk güvenli öneriye kadar ilerler. `otonom planla`
ise hiçbir coding önerisi başlatmadan planı incelemeye bırakır. Uygulama aşamasında mevcut
`kod değişikliğini onayla` sözleşmesi zorunludur; yazım toleransı onay ifadelerine uygulanmaz.

Doğrulama yalnızca proje içindeki göreli `.py` yollarını kabul eder. Test bulunamaması başarı
sayılmaz ve insan incelemesi gerektirir. Kaynak drift, checkpoint bütünlüğü, proje kilidi,
üç denemelik retry ve yedi günlük plan süresi korunur.
