# Börü V10.0

V10.0, içe aktarılan veya proje içindeki bir repoyu bağımsız çalışma alanı olarak seçer.

- `repo seç: repositories/github/owner/repo`: aktif kökü seçer ve yeniden başlatma için saklar.
- `repo durum`, `repo bırak`, `repo günlüğü`: yaşam döngüsünü ve denetim izini yönetir.
- `repo geliştir: hedef`: Architect, Coding, sandbox test, Security ve Code Review akışını seçili kökte çalıştırır.
- `repo doğrula: dosya.py`: ilişkili testleri Docker içinde seçili repo çalışma dizininde doğrular.
- `repo git durum`: yalnızca seçili kökte gerçek `.git` metadata varsa güvenli Git politikasını kullanır.

Repo kaynakları güvenilmeyen veri kabul edilir. Bekleyen onay varken çalışma alanı değiştirilemez;
dosya kapsamı ve testler ana Börü projesinden ayrıdır.
